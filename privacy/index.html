개인정보 처리방침

시행일: 2026년 11월 18일 · 운영자: Dearly 운영자

Dearly는 회원가입 없이 메모, 사진, 목소리를 기기에 기록하는 앱입니다. 이 방침은 Dearly 앱의 기록과, 운영자에게 직접 보내는 문의 정보를 어떻게 처리하는지 설명합니다.

  • 기록과 저장
  • 선택 권한
  • 백업과 외부 서비스
  • 삭제
  • 문의와 권리

기록은 기기에 저장합니다

입력한 제목·본문, 선택한 사진, 녹음한 음성, 기록 대상과 작성 시각 등의 기록 정보는 앱의 기록 표시·검색·재생을 위해 해당 기기의 앱 저장 공간에 보관합니다. 알림 사용 여부 등 기능 설정도 기기에 저장합니다.

현재 출시 앱에는 계정 가입이나 로그인 기능이 없습니다. 운영자는 앱에 작성한 기록을 Dearly 서버로 자동 전송하거나 열람하지 않으며, 별도의 자체 클라우드 동기화 서비스를 제공하지 않습니다.

Dearly 앱에는 광고 SDK나 앱 자체의 이용 행태 분석 SDK를 사용하지 않습니다. 운영체제나 앱 배포 서비스가 사용자의 설정과 해당 서비스 정책에 따라 처리하는 진단 정보는 Dearly의 자체 분석 기능과 구분됩니다.

권한은 필요한 기능에서 선택합니다

  • 사진 선택: 사용자가 선택한 사진을 기록에 첨부하기 위해 사용합니다.
  • 카메라: 앱에서 직접 사진을 촬영해 첨부할 때 사용합니다.
  • 마이크: 사용자가 시작한 음성 녹음을 기록에 첨부하기 위해 사용합니다.
  • 알림: 사용자가 켠 주간 질문 알림을 기기에서 표시하기 위해 사용합니다.

이 권한들은 선택 사항입니다. 허용하지 않아도 메모 등 관련 권한이 필요하지 않은 기능은 사용할 수 있습니다. 기기의 설정 앱에서 권한을 변경하거나, Dearly 설정에서 주간 알림을 끌 수 있습니다.

백업과 외부 서비스

사용자가 ‘백업 내보내기’를 실행하면 기록 정보와 실제 사진·음성 파일을 포함한 ZIP 파일을 만듭니다. 백업 파일은 별도로 암호화되지 않으므로, 파일을 가진 사람이 내용을 열어볼 수 있습니다. 안전한 위치에 보관하고 필요한 상대에게만 공유해주세요.

백업을 파일 앱, 클라우드 저장소, 이메일 등 다른 앱으로 저장하거나 공유하면 사용자가 선택한 외부 서비스가 그 파일을 처리합니다. 저장 위치, 접근 권한, 보관과 삭제는 해당 서비스의 설정과 정책에 따릅니다. 공유 화면을 닫았다는 사실만으로 외부에 백업이 저장된 것은 아닙니다.

백업을 가져올 때는 파일을 확인한 후 기존 기록을 유지하면서 새 기록을 추가합니다. 이미 같은 기록 ID가 있는 항목은 덮어쓰지 않고 건너뜁니다.

iCloud 등 운영체제의 기기 백업 설정에 따라 앱 데이터가 기기 백업에 포함될 수 있습니다. 이는 Dearly가 자체 서버로 기록을 자동 업로드하거나 기기 사이에서 실시간 동기화하는 기능과는 다릅니다. 운영체제의 백업 설정과 복원 가능 여부는 해당 서비스에서 확인해주세요.

기록의 보관과 삭제

기록은 사용자가 앱에서 삭제하거나 앱 데이터가 제거될 때까지 기기에 보관됩니다. 앱의 기록 상세 화면에서 개별 기록을 삭제할 수 있습니다. 운영자가 사용자의 기기 안에 있는 기록을 대신 조회하거나 삭제할 수는 없습니다.

앱 삭제, 기기 초기화·분실 또는 앱 데이터 제거로 기록이 사라질 수 있습니다. 운영자가 보관하는 기록 사본은 없으므로, 사용 가능한 백업이 없다면 운영자를 통한 복구는 제공할 수 없습니다.

앱에서 기록을 삭제해도 이미 외부에 내보낸 ZIP 파일이나 운영체제의 이전 백업까지 함께 삭제되지는 않습니다. 해당 파일과 백업은 사용자가 별도로 관리해야 합니다.

문의 정보와 개인정보 관련 요청

문의처는 ziglab.dev@gmail.com이며, 담당자는 Dearly 운영자입니다.

이메일을 보내면 이메일 주소, 문의 내용과 사용자가 첨부한 파일이 이메일 서비스 제공자를 통해 전송·보관됩니다. 운영자는 전달받은 정보를 문의 확인과 응대에 필요한 범위에서 사용합니다. 문의에 불필요한 가족의 사진·음성, 민감한 정보나 백업 전체 파일은 보내지 않아도 됩니다.

문의 정보는 응대에 필요한 동안 보관하고 더 이상 필요하지 않으면 삭제합니다. 관련 법령에 따른 보관 의무가 있는 경우에는 그 기준을 따릅니다. 운영자가 문의 과정에서 받은 개인정보의 열람·정정·삭제 등 요청은 위 이메일로 보내주세요. 기기 내 기록의 변경·삭제 방법도 안내합니다.

방침 변경

앱의 정보 처리 방식이나 관련 기준이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 중요한 변경 사항은 앱 또는 이 페이지를 통해 안내합니다.
