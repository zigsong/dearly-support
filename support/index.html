사용 방법과 문의

기록은 이 기기에 저장됩니다. 앱 삭제나 기기 변경 전에 백업 파일을 내보내고, 저장된 위치를 확인해주세요.

백업 파일 만들기

  1. Dearly의 설정 화면에서 ‘기록 저장 공간’을 찾습니다.
  2. ‘백업 내보내기’를 누르고 ZIP 파일이 만들어질 때까지 기다립니다.
  3. 공유 화면에서 파일 앱이나 원하는 저장소를 선택해 저장합니다.
  4. 선택한 위치에 ZIP 파일이 실제로 저장됐는지 확인합니다. 공유 화면에서 취소했다면 백업이 남지 않을 수 있습니다.

ZIP에는 메모·사진·목소리가 함께 들어 있으며 별도로 암호화되지 않습니다. 가족 기록이 담긴 파일이므로 보관 위치와 공유 대상을 확인해주세요.

백업 파일 가져오기

  1. 복원할 기기에서 백업 ZIP 파일에 접근할 수 있도록 준비합니다.
  2. Dearly 설정의 ‘기록 저장 공간’에서 ‘백업 가져오기’를 누릅니다.
  3. Dearly에서 내보낸 ZIP 파일을 선택합니다. 압축을 풀거나 내부 파일을 수정하지 않아도 됩니다.
  4. 추가할 기록과 중복 기록 수를 확인하고 가져오기를 진행합니다.

기존 기록은 유지합니다. 같은 기록 ID가 이미 있으면 해당 항목은 건너뛰며, 기존 내용을 덮어쓰지 않습니다. 손상되었거나 지원하지 않는 백업은 가져올 수 없습니다.

자주 묻는 질문

새 휴대전화로 기록을 옮기려면 어떻게 하나요?

기존 기기에서 백업을 내보낸 뒤, 파일 앱이나 직접 선택한 저장소를 통해 새 기기로 ZIP 파일을 옮기고 Dearly에서 가져와주세요. 계정 로그인으로 기록을 자동 이전하는 기능은 없습니다. 기존 기기를 초기화하기 전에 새 기기에서 기록과 첨부 파일이 열리는지 확인해주세요.

앱을 지웠거나 휴대전화를 잃어버렸어요.

별도로 보관한 Dearly 백업 ZIP이 있다면 다시 설치한 앱에서 가져올 수 있습니다. 운영체제의 기기 백업이 있다면 해당 운영체제가 제공하는 복원 방법도 확인해주세요. Dearly 운영자는 기록 사본을 보관하지 않으므로, 사용 가능한 백업이 없다면 기록을 복구해드릴 수 없습니다.

사진·카메라·마이크 권한을 다시 켜려면 어떻게 하나요?

iPhone의 설정 앱에서 ‘앱’ → ‘Dearly’를 열고 필요한 사진·카메라·마이크 접근 권한을 확인해주세요. iOS 버전에 따라 메뉴 위치가 다를 수 있습니다. 사진 접근이 제한된 경우에는 첨부하려는 사진을 허용하거나 사진을 다시 선택해주세요. 마이크는 녹음할 때만 필요하며, 권한 없이도 메모를 남길 수 있습니다.

질문 알림을 켜거나 끄고 싶어요.

Dearly 설정의 ‘이번 주의 질문 알림’에서 변경할 수 있습니다. 알림을 켰는데 도착하지 않으면 iPhone 설정의 Dearly 알림 권한과 집중 모드도 확인해주세요. 주간 알림은 기기 현지 시간 기준 매주 일요일 오후 6시로 설정됩니다.

백업 가져오기에 실패하거나 공간이 부족하다고 나와요.

기기의 여유 공간을 확보하고 원본 ZIP 파일로 다시 시도해주세요. 백업을 확인하고 복사하는 동안에는 ZIP 파일 자체보다 더 많은 임시 저장 공간이 필요할 수 있습니다. iPhone 앱은 최대 1GB, 웹 미리보기는 최대 100MB의 백업을 지원합니다. 실패한 가져오기로 기존 기록을 덮어쓰지는 않습니다.

같은 백업을 다시 가져오면 기록이 중복되나요?

현재 앱에 같은 ID의 기록이 있으면 건너뜁니다. 백업에 담긴 내용이 달라도 동일 ID의 기존 기록은 덮어쓰지 않습니다. 제목이나 사진이 같다는 이유만으로 서로 다른 ID의 기록까지 합치지는 않습니다.

사진과 녹음은 얼마나 담을 수 있나요?

새 기록에는 사진을 최대 5장까지 담을 수 있습니다. 새 사진은 긴 변을 최대 2048픽셀로 조정하고 JPEG로 저장하며, 한 장당 8MB까지 지원합니다. 새 녹음은 최대 10분·20MB입니다. 이 제한을 적용하기 전에 저장한 기록이나 백업을 임의로 줄이거나 다시 압축하지 않습니다.

웹 미리보기와 앱의 기록은 함께 보이나요?

자동으로 동기화되지 않습니다. 웹 미리보기는 사용하는 브라우저의 저장 공간에 보관하며, 브라우저 데이터 제거로 기록이 사라질 수 있습니다. 기록을 옮길 때는 백업 내보내기와 가져오기를 사용해주세요.
